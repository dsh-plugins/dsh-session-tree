## 数据与适配边界

使用当前官方版本 4 内存事件和编解码器，支持官方 JSONL 与 Zstandard 文件编码。真实实例使用默认压缩存储。未知格式不会直接改写；历史迁移由官方存储读取接口执行。

同 ID 历史替换会关闭并恢复 Agent，在恢复前处理真实待发队列，避免旧插入事件重新发送。截断的开放轮次使用官方 fork 收尾事件，不标记为崩溃恢复。

客户端采用官方公开 `resync()` 重建历史，并重置投影水位。loader 仅在内部重建期间暂缓 `api-session/removed`，真实会话删除仍按原行为通知。

本次没有发布 npm 或推送远程。插件需要本次配套 loader 构建，不能仅凭已有 `2.0.0` 版本号判断会话扩展已存在。
